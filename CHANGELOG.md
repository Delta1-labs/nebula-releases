# Changelog

All notable changes to Nebula.NET. Download any version from the
[Releases](https://github.com/Delta1-labs/nebula-releases/releases) page.

## 1.0.9
- **Enterprise edition** — new top tier with **per-customer watermarking** (leak tracing) and an aggressive control-flow tier, unlocked by an enterprise license.
- Multi-product, product-scoped licensing.
- Online activation improvements and fixes.

## 1.0.8
- Online license activation (seat-based, with instant revocation) and machine-bound offline leases.
- Identifier renaming, control-flow flattening, per-build string encryption, anti-tamper & anti-debug, resource & metadata hardening, Authenticode signing.
- CLI, desktop GUI, and MSBuild/CI integration.
- Verified to run identically to the original build across .NET Framework 4.8 and .NET 6–10.
